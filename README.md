# Marathi Fast News Portal

Welcome to the Marathi Fast News Portal!

This is a premium, full-stack news application built with React, Vite, Express, and SQLite.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
